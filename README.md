# Calculator

Консольный калькулятор на Python, который последовательно развивался от простой реализации арифметических операций до версии с конфигурацией, логированием, форматированным выводом и тестированием.

Проект создавался в **Replit** в рамках практического обучения Python, а затем был перенесён на **GitHub**. Репозиторий сохраняет несколько этапов развития программы — от первой версии до наиболее функциональной.

## Возможности

В разных версиях реализованы:

* арифметические операции;
* возведение в степень;
* целочисленное деление и остаток от деления;
* обработка деления на ноль;
* вычисление среднеквадратичного отклонения;
* функциональная декомпозиция;
* работа с конфигурационными файлами;
* настройка точности результатов;
* форматированный вывод;
* логирование операций;
* автоматизированное тестирование.

## Версии

### v.01 — базовая версия

Первая реализация консольного калькулятора.

Содержит основные арифметические операции и обработку пользовательского ввода.

**Основные технологии:** Python.

### v.02 — функциональная декомпозиция

Программа расширена и разделена на отдельные функции.

Добавлены вычисление среднеквадратичного отклонения, настройка точности, конфигурационные параметры, логирование и первые автоматизированные проверки.

**Основные технологии:** Python, NumPy.

### v.03 — форматирование результатов

В версии добавлен табличный вывод результатов.

Также проведены эксперименты с разными способами формирования таблиц — средствами Python и с использованием сторонней библиотеки.

**Основные технологии:** Python, NumPy, tabulate, PrettyTable.

### v.04 — конфигурация, логирование и тестирование

Наиболее развитая версия проекта.

Добавлены конфигурационные параметры, форматированный вывод, журналирование операций с датой и временем и отдельный тест функции записи в лог.

**Основные технологии:** Python, NumPy, tabulate.

## Развитие проекта

```text
v.01
Базовые арифметические операции
        ↓
v.02
Функции + конфигурация + вычисления + тестирование
        ↓
v.03
Форматированный вывод + эксперименты
        ↓
v.04
Конфигурация + логирование + тестирование
```

Таким образом, проект демонстрирует постепенное усложнение одной программы и освоение различных аспектов разработки на Python.

## Структура

```text
calculator/
│
├── v.01/
│   └── Базовая реализация
│
├── v.02/
│   └── Расширенная функциональность
│
├── v.03/
│   └── Форматированный вывод и эксперименты
│
└── v.04/
    └── Конфигурация, логирование и тестирование
```

Каждая версия содержит собственный код и необходимые для неё конфигурационные файлы и зависимости.

## Среда разработки

Первоначально проект разрабатывался в **Replit**.

В процессе работы проект проходил миграцию виртуального окружения в Replit. Служебные файлы, связанные с этой миграцией, сохранились в некоторых версиях проекта.

После этого исходный код был перенесён на **GitHub**, где версии проекта собраны в едином репозитории.
