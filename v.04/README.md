# Calculator v.04

Четвёртая версия консольного калькулятора на Python.

Это наиболее развитая версия проекта. В ней продолжена работа с конфигурацией программы, форматированием результатов и журналированием. Также добавлен отдельный тест для проверки записи данных в журнал.

## Возможности

Калькулятор поддерживает:

* `+` — сложение;
* `-` — вычитание;
* `*` — умножение;
* `/` — деление;
* `^` — возведение в степень;
* `//` — целочисленное деление;
* `%` — остаток от деления.

Дополнительно реализованы:

* настройка параметров вычислений через `params.ini`;
* настройка операций через `settings.ini`;
* управление точностью результатов;
* форматированный вывод результатов;
* запись истории вычислений в журнал;
* запись даты и времени выполнения операций;
* автоматизированная проверка функции журналирования.

## Тестирование

Для проверки работы журналирования используется отдельный файл:

```text id="7g1xat"
test_write_log.py
```

Тест проверяет корректность работы функции записи данных в журнал.

## Конфигурация

Работа программы настраивается с помощью конфигурационных файлов:

`params.ini` — параметры вычислений и вывода результатов.

`settings.ini` — значения, используемые программой при выполнении операций.

Такой подход позволяет изменять настройки без непосредственного изменения исходного кода.

## Структура

```text id="3xw4vb"
v.04/
├── main.py
├── test_write_log.py
├── params.ini
├── settings.ini
├── pyproject.toml
├── poetry.lock
├── VENV.md
└── calc-history.log.txt
```

`main.py` — основная программа.

`test_write_log.py` — тест функции журналирования.

`params.ini` — параметры программы.

`settings.ini` — настройки операций.

`pyproject.toml` — настройки проекта и зависимости.

`poetry.lock` — зафиксированные версии зависимостей.

`VENV.md` — информация о миграции виртуального окружения в Replit.

`calc-history.log.txt` — журнал вычислений.

## История проекта

Проект первоначально разрабатывался в **Replit**. В процессе работы Replit обновлял инфраструктуру виртуальных окружений, что отражено в файле `VENV.md`.

После разработки исходный код был перенесён в GitHub.

`v.04` является следующим этапом развития проекта после `v.01`, `v.02` и `v.03`. По сравнению с предыдущими версиями здесь продолжена работа с конфигурацией, форматированием вывода, журналированием и тестированием.
