# Calculator v.03

Третья версия консольного калькулятора на Python.

В этой версии проект продолжает развиваться: добавлен форматированный вывод результатов в виде таблиц, а также проведены эксперименты с несколькими способами представления данных в консоли.

## Что добавлено

* форматированный вывод результатов;
* использование библиотеки `tabulate`;
* сохранение истории вычислений;
* отдельные экспериментальные реализации табличного вывода;
* сравнение разных подходов к форматированию данных.

## Основные возможности

Калькулятор поддерживает арифметические операции:

* `+` — сложение;
* `-` — вычитание;
* `*` — умножение;
* `/` — деление;
* `^` — возведение в степень;
* `//` — целочисленное деление;
* `%` — остаток от деления.

Параметры вычислений задаются через конфигурационный файл `params.ini`.

Результаты работы программы могут выводиться в структурированном табличном виде и сохраняться в журнал.

## Эксперименты

В проекте присутствуют два экспериментальных файла:

`experiments.py` — собственная реализация форматирования таблицы.

`experiments2.py` — альтернативный вариант с использованием библиотеки `PrettyTable`.

Эксперименты позволяют сравнить собственную реализацию с готовыми инструментами для форматирования вывода.

## Структура

```text
v.03/
├── main.py
├── experiments.py
├── experiments2.py
├── params.ini
├── pyproject.toml
├── poetry.lock
├── VENV.md
└── calc-history.log.txt
```

`main.py` — основная программа калькулятора.

`experiments.py` — эксперимент с собственной реализацией табличного вывода.

`experiments2.py` — эксперимент с использованием `PrettyTable`.

`params.ini` — параметры работы программы.

`pyproject.toml` — настройки проекта и зависимости.

`poetry.lock` — зафиксированные версии зависимостей.

`VENV.md` — информация о миграции виртуального окружения в Replit.

`calc-history.log.txt` — журнал вычислений.

## Технологии

* Python
* NumPy
* Poetry

## Запуск

```bash
python main.py
```

Экспериментальные реализации можно запустить отдельно:

```bash
python experiments.py
```

```bash
python experiments2.py
```

## История проекта

Проект первоначально разрабатывался в **Replit**. В процессе работы Replit обновлял инфраструктуру виртуальных окружений, что отражено в файле `VENV.md`.

После разработки исходный код был перенесён в GitHub.

`v.03` продолжает развитие проекта после `v.01` и `v.02`, добавляя более структурированный вывод результатов и эксперименты с различными способами форматирования данных.
