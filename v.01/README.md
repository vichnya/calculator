# Calculator v.01

Первая версия консольного калькулятора на Python.

Проект создавался как практическая работа с базовыми конструкциями Python и постепенно развивался в следующих версиях (`v.02`, `v.03`, `v.04`).

## Возможности

Калькулятор поддерживает основные арифметические операции:

* `+` — сложение;
* `-` — вычитание;
* `*` — умножение;
* `/` — деление;
* `^` — возведение в степень;
* `//` — целочисленное деление;
* `%` — остаток от деления.

Также предусмотрена проверка деления на ноль и обработка неизвестного оператора.

## Как работает

Пользователь вводит:

1. первое число;
2. оператор;
3. второе число.

После этого программа выполняет выбранную операцию и выводит результат в консоль.

## Технологии

* Python

## Запуск

```bash

```

## История проекта

Первая версия была разработана в среде **Replit**. В дальнейшем проект развивался и был перенесён в GitHub.

При работе с Replit использовалась его система виртуального окружения. В процессе обновления инфраструктуры Replit происходила миграция legacy-виртуального окружения, что отражено в материалах следующих версий проекта.

## Развитие

`v.01` → базовая реализация калькулятора

`v.02` → функции, конфигурация, вычисление стандартного отклонения, журналирование и тесты

`v.03` → форматированный вывод результатов и эксперименты с представлением таблиц

`v.04` → дальнейшая работа с настройками, журналированием и тестированием
