# Calculator v.02

Вторая версия консольного калькулятора на Python.

В этой версии проект был расширен по сравнению с `v.01`: логика программы разделена на отдельные функции, добавлена работа с параметрами из конфигурационного файла, вычисление стандартного отклонения, журналирование результатов и первые автоматизированные тесты.

## Что добавлено

* разделение логики программы на отдельные функции;
* настройка параметров через `params.ini`;
* настройка точности вычислений;
* вычисление среднего значения и стандартного отклонения;
* запись результатов вычислений в журнал;
* автоматизированные проверки с помощью `tests.py`;
* использование библиотеки NumPy для математических вычислений.

## Основные возможности

Калькулятор поддерживает операции:

* `+` — сложение;
* `-` — вычитание;
* `*` — умножение;
* `/` — деление;
* `^` — возведение в степень;
* `//` — целочисленное деление;
* `%` — остаток от деления.

Дополнительно реализовано вычисление стандартного отклонения для набора чисел.

Параметры программы можно изменять без изменения исходного кода — они задаются в файле `params.ini`.

## Тестирование

Для проверки отдельных частей программы используется файл `tests.py`.

Тесты проверяют, в частности:

* загрузку параметров из конфигурационного файла;
* корректность выполнения операций;
* работу с заданной точностью результата.

## Структура

```text
v.02/
├── main.py
├── tests.py
├── params.ini
├── pyproject.toml
├── poetry.lock
├── VENV.md
└── calc-history.log.txt
```

`main.py` — основная логика калькулятора.

`tests.py` — автоматизированные проверки.

`params.ini` — параметры работы программы.

`pyproject.toml` — настройки проекта и зависимости.

`poetry.lock` — зафиксированные версии зависимостей.

`VENV.md` — информация о миграции виртуального окружения в Replit.

`calc-history.log.txt` — журнал выполненных вычислений.

## Технологии

* Python
* NumPy
* Poetry
* Replit

## Запуск

```bash
python main.py
```

Для запуска тестов:

```bash
python tests.py
```

## История проекта

Проект первоначально разрабатывался в **Replit**. В процессе работы Replit обновлял инфраструктуру виртуальных окружений, поэтому в проекте сохранился файл `VENV.md` с информацией об этой миграции.

После разработки исходный код был перенесён в GitHub. Версия `v.02` является следующим этапом развития калькулятора после `v.01`.
